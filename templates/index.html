Contoh: D:\Konten\postingan1. music diisi nama lagu; GAMA mencarinya di library TikTok dan hanya memasang yang judulnya cocok. Kosongkan kalau tidak pakai musik.

 Downloader

                
    
                    
  1. Mode Per Link: tempel satu/banyak URL video untuk diunduh.
    2.

  3. Hasil olahan otomatis tersimpan dan siap dipakai lagi di Uploader.

 Pengaturan AI

            
API Key untuk AI Caption & Prompt Generator. Bisa isi banyak key - satu key per baris (otomatis rotasi kalau kena limit).


            

                

                    
 API Keys (Gemini & Groq)

                    

                        
                        
                        Prompt Generator (analisa gambar) selalu memakai Gemini; Groq hanya untuk caption teks.
                    

                    

                        
                        
                    

                    

                        
                        
                    

                

                

                    
 Dapatkan API Key Gratis

                    
Klik untuk membuka halaman pembuatan API key. Tip: buat beberapa key Gemini dari akun Google berbeda - tiap akun punya kuota gratis sendiri. Tempel semua (satu key per baris) -> otomatis rotasi saat satu kena limit.

                    

                        
                        
                    

                    
Fitur Prompt Generator, Auto Prompt, dan Tiru Video hanya jalan dengan Gemini (Groq tak bisa membaca gambar/video). Jadi kalau sering kena limit, isi beberapa key Gemini dari akun Google berbeda.
